Quick setup

Run these commands in the folder where you want to keep the token. OpenSSL must be installed and available in your terminal.

Linux or macOS

openssl rand -hex 32 > ./xboost-token
codex app-server --listen ws://0.0.0.0:4500 \
  --ws-auth capability-token \
  --ws-token-file ./xboost-token

Windows PowerShell

openssl rand -hex 32 | Set-Content -NoNewline .\xboost-token
codex app-server --listen ws://0.0.0.0:4500 --ws-auth capability-token --ws-token-file .\xboost-token

Keep that terminal running. Below, use ws://127.0.0.1:4500 on the same computer, or ws://YOUR-LAN-IP:4500 from another device. Paste the token file's contents into the capability token field.

Plain ws:// exposes your capability token and messages to network observers. Prefer ws://127.0.0.1 with SSH forwarding, or wss:// through a TLS proxy for remote servers. Never paste a token into a public support message.

Scoring stays local. Optional AI sends post text, author handles, post URLs and product context to your Codex server and OpenAI. Assisted replies fill X's composer only at your request; sending remains manual. Privacy policy.
